# بوتیک هتل سنتی فرهادی شیراز (Farhadi Boutique Hotel)

وب‌سایت رسمی و پرفورمنس‌محور **بوتیک هتل سنتی فرهادی** واقع در بافت تاریخی شیراز، ایران.

توسعه‌یافته بر پایه **Next.js (App Router)**، **TypeScript**، **Tailwind CSS v4** و کامپوننت‌های **shadcn/ui** با رعایت کامل چیدمان راست‌به‌چپ (RTL) و فونت اختصاصی استعداد (Estedad).

---

## 🏛️ ویژگی‌های پروژه

- **طراحی تصویرمحور و مدرن:** الهام‌گرفته از استانداردهای معماری معاصر (Samara ADUs) و تلفیق با اصالت، رنگ‌ها و نوستالژی معماری قاجار و پهلوی.
- **هویت بصری و لوگوی عمارت:** بازآفرینی هندسه زرین، طاق قوسی و اسلیمی کاشی‌کاری‌های سنتی.
- **واحدهای اقامتی اختصاصی:** تالار آینه قاجاری، سوئیت رویال شاه‌نشین، اتاق پنج‌دری، اتاق دبل سنتی، اتاق ارسی و سوئیت خانوادگی.
- **مسیر مستقیم رزرو و اقدام (CTA):** اتصال مستقیم فرم‌ها و دکمه‌های تماس و استعلام به واتس‌اپ هتل و خطوط تلفنی پذیرش.
- **گالری عکس تعاملی با لایت‌باکس:** تب‌های فیلتر دسته‌بندی‌شده و قابلیت نمایش تصویر بزرگ با ناوبری RTL.
- **نقشه تعاملی با Leaflet:** نشانگر اختصاصی عمارت در سه‌راه نمازی (خیابان شهید دستغیب، کوچه ۶) و نمایش فاصله پیاده‌روی تا حرم شاهچراغ (ع)، بازار وکیل و مسجد نصیرالملک، به همراه لینک‌های مستقیم مسیریابی گوگل‌مپ، نشان و بلد.

---

## 🚀 راه‌اندازی محلی (Development)

برای اجرای پروژه در محیط لوکال:

```bash
# نصب پکیج‌ها
npm install

# اجرای سرور توسعه
npm run dev
```

سپس در مرورگر خود آدرس [http://localhost:3000](http://localhost:3000) را باز کنید.

## 📦 بیلد پروداکشن (Build)

```bash
npm run build
npm run start
```
