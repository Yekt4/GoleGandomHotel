# هتل آپارتمان گل گندم مشهد

وب‌سایت معرفی **هتل آپارتمان گل گندم مشهد**، نمایش اتاق‌ها و امکانات و ارتباط مستقیم با پذیرش برای استعلام و رزرو. مجموعه در مشهد، خیابان امام رضا ۶۴، نبش چهارراه اول قرار دارد.

پروژه با **Next.js 16 (App Router)**، **React 19**، **TypeScript**، **Tailwind CSS v4** و کامپوننت‌های **shadcn/ui** ساخته شده است. رابط فارسی راست‌به‌چپ و نسخهٔ انگلیسی دارد و برای موبایل و دسکتاپ طراحی شده است.

## بخش‌ها و قابلیت‌ها

- **هویت بصری:** رنگ‌های قهوه‌ای، طلایی گندمی و عاجی، لوگوی گل گندم، فونت استعداد و پترن‌های الهام‌گرفته از کاشی‌کاری و نقوش مذهبی.
- **هیرو:** اسلایدشوی ۱۰ تصویر از مشهد، با تصویر گنبد حرم امام رضا در شب در ابتدای مجموعه.
- **ویدیوها:** معرفی مشهد و جاذبه‌های اطراف با ویدیوهای محلی.
- **روایت اقامت:** حال‌وهوای سفر به مشهد همراه با تصاویر ورودی، رستوران و لابی هتل آپارتمان.
- **اتاق‌ها:** معرفی ۶ نوع اتاق شامل یک‌تخته، دو‌تخته دابل، دو‌تخته تویین، سه‌تخته، چهار‌تخته و پنج‌تخته؛ همراه با مشخصات، تصاویر و فیلتر نوع اتاق.
- **آلبوم تصاویر:** دسته‌بندی نمای هتل، اتاق‌ها، رستوران و کافی‌شاپ، لابی و پذیرش، با نمایش بزرگ تصاویر.
- **امکانات و خدمات:** از جمله آسانسور، اینترنت رایگان محدود، سرویس رفت به حرم، امانت کارت بی‌آرتی و اقامت رایگان یک کودک زیر ۳ سال.
- **موقعیت:** نقشهٔ تعاملی Leaflet، مکان‌های مهم اطراف، فاصله و زمان دسترسی و لینک‌های مسیریابی.
- **ارتباط و رزرو:** تماس تلفنی و واتس‌اپ پذیرش، اطلاعات اقامت و مدارک مورد نیاز. استعلام و هماهنگی رزرو از طریق پذیرش انجام می‌شود.
- **اسنپ‌پی:** نمایش اطلاع‌رسانی امکان پرداخت اقساطی بر اساس تنظیمات پروژه؛ سایت درگاه پرداخت یا فرایند تکمیل رزرو آنلاین ندارد.
- **آمار:** ثبت رویدادهای بازدید و تعامل، حفظ پارامترهای UTM و داشبورد محافظت‌شدهٔ `/stats` با خروجی CSV.

## ساختار و محل ویرایش محتوا

پروژه پیکربندی‌محور است و می‌توان آن را با هویت هتل‌های دیگر تطبیق داد. هویت، راه‌های ارتباط و موقعیت در فایل پیکربندی مرکزی قرار دارند؛ متن‌ها و محتوای تصویری در فایل ترجمه‌ها مدیریت می‌شوند.

| مسیر | کاربرد |
| --- | --- |
| `src/config/hotel.config.ts` | هویت هتل، شماره‌ها، شبکه‌های اجتماعی، نشانی، مختصات، جاذبه‌ها، اسنپ‌پی و اطلاعات سئو |
| `src/lib/translations.ts` | متن‌های فارسی و انگلیسی، فهرست و مشخصات اتاق‌ها، ترتیب تصاویر هیرو، آلبوم، ویدیوها، امکانات و قوانین |
| `src/components/` | کامپوننت‌های بخش‌های صفحه و رابط کاربری |
| `src/context/LanguageContext.tsx` | مدیریت زبان و جهت نمایش |
| `src/app/globals.css` | استایل‌های عمومی، فونت‌ها و متغیرهای تم |
| `src/app/page.tsx` | ترتیب بخش‌های صفحهٔ اصلی |
| `src/app/stats/page.tsx` | رابط داشبورد آمار |
| `src/lib/tracker.ts` | ثبت تعامل‌ها و انتساب UTM |
| `src/lib/analytics-store.ts` | ذخیره و پردازش رویدادهای آماری |
| `src/lib/auth.ts` | احراز هویت و نشست پنل آمار |
| `src/app/api/` | مسیرهای سمت سرور برای ثبت رویداد، آمار و احراز هویت |
| `public/images/` و `public/videos/` | تصاویر و ویدیوهای محلی سایت |

اطلاعات اتاق‌ها در همین نسخه داخل `src/lib/translations.ts` است. برای تغییر محتوا، هر دو زبان را هماهنگ ویرایش کنید. ترتیب آرایهٔ `hero.images` ترتیب نمایش عکس‌های هیرو را تعیین می‌کند و اولین عضو، تصویر آغازین است.

## راه‌اندازی محلی

پیش‌نیاز: Node.js سازگار با Next.js 16 و npm.

```bash
git clone https://github.com/Yekt4/GoleGandomHotel.git
cd GoleGandomHotel
npm ci
```

فایل `.env.example` را به `.env.local` کپی کنید. نام کاربری، رمز عبور و کلید امضای نشست پنل آمار را با مقادیر اختصاصی تنظیم کنید؛ مقادیر نمونه و پیش‌فرض کد برای انتشار مناسب نیستند.

```dotenv
STATS_ADMIN_USERNAME=your-admin-name
STATS_ADMIN_PASSWORD=your-unique-password
STATS_SESSION_SECRET=your-long-random-secret
```

سپس سرور توسعه را اجرا کنید:

```bash
npm run dev
```

سایت در [localhost:3000](http://localhost:3000) و پنل آمار در [localhost:3000/stats](http://localhost:3000/stats) در دسترس‌اند. سرور باید هنگام مشاهدهٔ سایت روشن بماند.

### مشاهده روی موبایل واقعی

گوشی و کامپیوتر را به یک شبکهٔ وای‌فای وصل کنید و سرور را با این دستور اجرا کنید:

```bash
npm run dev -- --hostname 0.0.0.0
```

در ویندوز با دستور `ipconfig`، مقدار `IPv4 Address` مربوط به Wi-Fi را پیدا کنید. سپس در مرورگر گوشی آدرس `http://<computer-ip>:3000` را باز کنید. دسترسی شبکه به پورت ۳۰۰۰ باید در فایروال مجاز باشد؛ `localhost` روی گوشی به خود گوشی اشاره می‌کند.

## بیلد و بررسی

```bash
npm run build
npm run start
```

برای بررسی ESLint:

```bash
npm run lint
```

## پنل آمار و نگهداری داده‌ها

پنل `/stats` با نام کاربری و رمز عبور، کپچا، محدودسازی تلاش ناموفق و نشست امضاشده محافظت می‌شود. فایل‌های `.env.local` و داده‌های محلی آمار در گیت قرار نمی‌گیرند.

رویدادها در `.data/analytics.json` ذخیره می‌شوند و ذخیره‌ساز فعلی حداکثر ۱۰٬۰۰۰ رویداد اخیر را نگه می‌دارد. محیط اجرا باید دسترسی نوشتن و فضای ذخیره‌سازی ماندگار داشته باشد؛ در محیط‌های با دیسک موقت یا چند نمونهٔ هم‌زمان، برای نگهداری قابل اتکای آمار به ذخیره‌ساز مشترک نیاز است. از داده‌های مورد نیاز نسخهٔ پشتیبان بگیرید.

## آماده‌سازی برای انتشار

پیش از انتشار، دامنهٔ سایت، اطلاعات سئو، مختصات و لینک‌های مسیریابی را در فایل پیکربندی بررسی کنید، اطلاعات پذیرش را با مجموعه تطبیق دهید و متغیرهای محیطی پنل آمار را در محیط مقصد تنظیم کنید. اجرای APIها و پنل آمار به سرور Next.js نیاز دارد؛ خروجی صرفاً ایستای صفحه برای تمام قابلیت‌های پروژه کافی نیست.
